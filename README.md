# Visink

Визуальный редактор диалогов в духе articy: реплики — карточки на холсте, развилки — стрелки, на выходе — обычные `.ink`-файлы. ТЗ — в `ТЗ визуальный редактор ink в духе articy.md`.

## Запуск

```sh
npm install
npm run dev      # http://localhost:5173, открывать в Chrome или Edge
npm test         # компилятор и проверки, ink компилируется inkjs
npm run demo     # пересоздать examples/demo.visink из тестовой фикстуры
```

В приложении: «Открыть…» → папка `examples/demo.visink` или «Новый проект…» → пустая папка. Ctrl+S сохраняет проект и, если нет ошибок, пишет сборку в `build/narrative` внутри проекта (или во внешнюю папку — кнопка «Собирать во внешнюю папку…» в свойствах проекта, например прямо в проект Godot).

## Настольное приложение (Tauri)

```sh
npm run desktop:dev     # окно приложения с горячей перезагрузкой (сам поднимает vite на 5173)
npm run desktop:build   # .app и .dmg в packages/desktop/src-tauri/target/release/bundle/
```

Нужен Rust (`rustup`). В приложении папки выбираются системным диалогом, последний проект открывается при запуске, внешняя папка сборки запоминается для каждого проекта. Файлы читает и пишет Rust (`packages/desktop/src-tauri/src/lib.rs`), только внутри выбранной папки.

## Рабочие режимы

- **Канвас** — карточки, связи и именованные карточки-вложенности. Двойной щелчок открывает содержимое, breadcrumbs сверху возвращают наверх. Внутренний поток начинается без отдельной стартовой карточки, а его свободные концы автоматически продолжают выходы родительской вложенности. Всё содержимое копируется вместе с родительской карточкой и компилируется в тот же `.ink`-файл, без отдельных игровых узлов.
- **Логика** — общая таблица переменных, редакторы LIST и функций, массовое выделение и удаление. Свойства персонажа пишутся как `ent_dean.trust`; в Ink они получают уникальное имя `ent_dean__trust`.
- **Персонажи** — настройки персонажа и его собственные переменные, списки и функции. У разных персонажей могут быть одинаковые локальные имена.
- **Тестирование** — запуск фактической сборки через inkjs, выбор файла или точки входа, продолжение, варианты выбора, просмотр тегов и переменных, переход к текущей карточке. Для EXTERNAL в прогоне используется запасное тело функции.

Дерево проекта слева объединяет глобальные переменные, файлы с вложенными потоками и персонажей. Постоянной правой колонки нет: свойства карточек, стрелок и проекта открываются контекстными диалогами.

## Как игра запускает диалог

- Каждый файл — отдельный диалог: узел ink с именем файла. У файла одно **начало** — карточка с флажком в шапке; новый файл создаётся с первой карточкой-началом, перенести начало — правый щелчок по карточке → «Сделать началом файла».
- Игра запускает диалог так: `ChoosePathString("dean")` — с начала файла.
- **Дополнительная точка входа** (свойства карточки) — если диалог иногда начинается не с начала, например со второй встречи: `ChoosePathString("dean.entry_second_meeting")`.
- **Переход** — карточка jump ведёт к файлу, точке входа или любой карточке по адресу `dean.c2`, включая реплики, хабы и содержимое вложенностей. Цель можно выбрать из списка с поиском.
- **Запуск всей истории** (свойства проекта) — куда переходит `main.ink`; нужен для Inky и прогона всей истории целиком. Godot его не использует.

## Пакеты

| Пакет | Что делает |
| --- | --- |
| `packages/core` | модель данных, стабильный JSON, загрузка и сохранение проекта через `ProjectFs` |
| `packages/compiler` | холсты → `main.ink`, `globals.ink`, файл на холст, `manifest.json`, карта строк ink ↔ карточек |

| `packages/app` | интерфейс: Vite + React + React Flow + Zustand (undo через zundo) |
| `packages/desktop` | настольное приложение на Tauri 2: окно, системные диалоги, файловые команды на Rust |

## Сборка для движка

- Узел ink = холст, стежок = id карточки (не меняется никогда). Игра запускает `ChoosePathString("dean")` (с первой карточки холста) или `ChoosePathString("dean.entry_first_meeting")` (карточка с точкой входа `first_meeting`).
- Ветка без стрелок заканчивается `-> DONE`. Конец игры и возврат из туннеля — карточкой «ink» с `-> END` / `->->`.
- Файлы холстов лежат плоско: `canvases/<id>.canvas.json`, в сборке `<id>.ink`. Старые проекты с папками-категориями и карточками «Вход»/«Конец» переводятся автоматически при открытии.
- У каждой строки теги `id: холст.карточка`, `speaker: ent_…`, по желанию `emotion:`, `dir:` и свои теги.
- `manifest.json` — холсты с точками входа, персонажи (имя, цвет, портрет) и тексты всех строк по id.
- Компилировать нужно только `main.ink` — остальные файлы подключены через `INCLUDE`.

## Правки 28.10, вечер

Без категорий холстов и без карточек «Вход»/«Конец» (точка входа — поле у любой карточки); меню «что вставить» при стрелке в пустоту и по правому щелчку; рамка выделения + общие настройки для нескольких карточек (Cmd/Ctrl + протянуть, два пальца — двигать холст); светлая и тёмная тема в духе articy; ошибки — значок в углу карточки; без текста на кнопке вариант показывает текст реплики; сборка удаляет свои устаревшие `.ink`.

## Правки 28.10, раунд 3

В интерфейсе «холст» → «файл» (формат на диске прежний). Выделением владеет React Flow — щелчок, Shift/Cmd+щелчок и рамка работают предсказуемо. Логика на стрелках: условие (когда показывать вариант / идти по стрелке) и действие при переходе, подписаны на самой стрелке, правятся в панели справа по щелчку на стрелку; ошибки в них подсвечивают стрелку. Цифры порядка на стрелках убраны — порядок по-прежнему сверху вниз. Кнопки — иконки lucide с подсказками, тема — кнопка-иконка. Широкая зона захвата пинов и прилипание стрелки к карточке. Границы трёх панелей перетаскиваются (двойной щелчок — сброс), размеры запоминаются.

## Правки 28.10, раунд 4

Скрытие левой/правой/нижней панели (кнопки в тулбаре, Ctrl+[ / Ctrl+] / Ctrl+\\). Общий поиск по проекту с группами. Переменные и списки — список имён, свойства справа, «где используется», переименование обновляет весь проект. Рамка выделяет всё, что задела. Свои выпадающие списки вместо браузерных. Явное начало файла. Служебное на карточке — в шапке, логика — полосой под ней, в теле только текст. Настольное приложение на Tauri.

## Правки 28.10, раунд 5

Статус гаснет через 3 с (ошибки — нет). Щелчок по холсту закрывает свойства переменной/персонажа/стрелки.
